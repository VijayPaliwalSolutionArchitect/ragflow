# Fork Rationale

This repository is a SHIVAM ITCS fork of [infiniflow/ragflow](https://github.com/infiniflow/ragflow) at commit `313ca90f`.

## Why this fork exists

We maintain a stable, debranded reference pin of the RAG engine to ensure a known, fixed version for our retrieval positioning in agentic AI systems. By pinning to a specific commit, we avoid unexpected changes from upstream while still benefiting from the core functionality.

## What this fork proves

- **Pinned-source intake**: The fork ingests exactly the specified upstream commit, preserving all upstream copyrights and licenses (Apache-2.0).
- **Upstream credit discipline**: All upstream attributions are preserved in NOTICE.md and LICENSE; no upstream code is modified.
- **Branding without alteration**: The fork presents a SHIVAM ITCS identity (via README.md and translated READMEs) while leaving upstream source untouched.

## What this fork is NOT

- Not affiliated with InfiniFlow or the upstream project.
- Not a redistribution product or a commercial offering of the upstream work.
- Not claiming any authorship over the upstream codebase.
